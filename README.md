# RZone

## Project Overview
RZone is a web application designed to provide a seamless user experience for managing resources and zones efficiently.

## Setup Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/ValyZone/rzone.git
   cd rzone
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the application:
   ```bash
   npm start
   ```

## Technology Stack
- **Frontend:** React.js
- **Backend:** Node.js, Express
- **Database:** MongoDB
